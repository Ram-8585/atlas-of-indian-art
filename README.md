# Atlas of Indian Art

An interactive map exploring India's artistic heritage — from the ancient cave paintings of Ajanta to the contemporary Kochi-Muziris Biennale.

**Live site:** https://ram-8585.github.io/atlas-of-indian-art/

## What's inside

- **14 art locations** across India (Delhi, Jaipur, Khajuraho, Madhubani, Ajanta, Ellora, Hampi, Thanjavur, Kochi, Kolkata, Santiniketan, Mumbai, Warli region, Agra)
- **Interactive SVG map** — markers positioned by real geographic coordinates, projected onto a simplified map of India
- **Era filters** — Ancient, Medieval, Early Modern, Modern, Contemporary, Traditional
- **Live search** across names, regions, traditions, artworks, and artists
- **Detail panel** for each location: artwork, artists, movement, description, and photos (via Wikimedia Commons)
- **Keyboard accessible** — arrow-key navigation, focus states, ARIA labels

## Tech

Single self-contained HTML file — HTML, CSS, and vanilla JavaScript. No dependencies, no build step. Just open `index.html` or visit the live site.
